# Анализ тарифов федерального мобильного оператора

## Описание проекта

Проект посвящён анализу клиентской базы федерального мобильного оператора и сравнению поведения пользователей двух тарифных планов: `Smart` и `Ultra`.

## Цель проекта

Проанализировать поведение клиентов мобильного оператора и определить, сколько пользователи разных тарифов тратят в среднем за месяц.

## Задачи проекта

- Изучить структуру данных и проверить качество таблиц.
- Проверить наличие пропусков и аномальных значений.
- Рассчитать месячную активность клиентов:
  - длительность звонков;
  - объём интернет-трафика;
  - количество SMS.
- Объединить данные о пользователях, тарифах и потреблении услуг.
- Рассчитать ежемесячные траты клиентов с учётом тарифных лимитов.
- Определить средние расходы активных клиентов по каждому тарифу.
- Найти клиентов, которые платят сверх абонентской платы, и рассчитать среднюю переплату.

## Основные выводы

- Большая часть клиентов остаётся активной: доля активных пользователей составляет **92,4%**.
- У каждого активного клиента используется только один тарифный план, что упрощает анализ.
- В данных о звонках есть звонки длительностью `0` минут. Их доля составляет около **19,6%**, вероятно, это пропущенные звонки.
- Пользователи тарифа `Smart` чаще выходят за лимиты и в среднем существенно переплачивают сверх абонентской платы.
- Средние месячные траты пользователей тарифа `Smart` составляют **1206.10 ₽**, что более чем в два раза выше базовой стоимости тарифа.
- Средние месячные траты пользователей тарифа `Ultra` составляют **2056.65 ₽**, что ненамного выше абонентской платы.
- Среди клиентов с переплатой пользователи тарифа `Smart` в среднем доплачивают **883.42 ₽**, а пользователи тарифа `Ultra` — **781.79 ₽**.

Рекомендуется:

- предложить пользователям тарифа `Smart`, которые часто выходят за лимиты, переход на более подходящий тариф;
- создать промежуточный тариф между `Smart` и `Ultra`;
- использовать данные о превышении лимитов для персональных предложений;
- анализировать клиентов с высокой переплатой как потенциальную группу риска по оттоку;
- отдельно изучить потребление интернет-трафика, так как именно интернет часто становится причиной дополнительных расходов.
