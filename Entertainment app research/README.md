# Разработка A/B-теста и анализ результатов для развлекательного приложения

**СТАТУС:** Завершён

---

## Цель проекта

Рассчитать параметры A/B-теста для проверки нового алгоритма рекомендаций в развлекательном приложении, проконтролировать корректность проведения эксперимента и проанализировать его результаты.

---

## Описание проекта

В проекте анализируется развлекательное приложение с бесконечной лентой контента.  
Команда разработчиков предложила новый алгоритм рекомендаций, который должен показывать пользователям более релевантный и интересный контент.

Основная гипотеза исследования: новый алгоритм рекомендаций увеличит вовлечённость пользователей в первые сессии.

В рамках проекта были:

- изучены исторические данные по сессиям пользователей;
- проведён исследовательский анализ данных;
- выбрана ключевая метрика A/B-теста;
- рассчитан необходимый размер выборки;
- оценена длительность эксперимента;
- проверена корректность распределения пользователей по группам;
- проанализированы результаты завершённого A/B-теста;
- проведена проверка статистической значимости различий между группами.

---

## Вывод исследования

Новый алгоритм рекомендаций не показал статистически значимого улучшения пользовательской вовлечённости.

Доля успешных первых сессий в тестовой группе B оказалась немного ниже, чем в контрольной группе A. Разница между группами составила -0.11 процентного пункта.

По результатам Z-теста для пропорций значение p-value оказалось больше уровня значимости 0.05, поэтому нет оснований отвергнуть нулевую гипотезу.

На основании результатов A/B-теста нельзя утверждать, что новый алгоритм рекомендаций улучшает поведение пользователей в первых сессиях.

---

## Бизнес-рекомендация

В текущем виде новый алгоритм рекомендаций не рекомендуется внедрять в продукт, так как он не показал статистически значимого положительного эффекта на ключевую метрику.

Рекомендуется:

- доработать алгоритм рекомендаций;
- провести дополнительный анализ поведения пользователей по сегментам;
- проверить влияние алгоритма на другие метрики, например глубину просмотра, длительность сессии и удержание;
- после доработки запустить повторный A/B-тест на новой выборке пользователей.
