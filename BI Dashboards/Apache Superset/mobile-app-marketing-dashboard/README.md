# Дашборд эффективности рекламных кампаний мобильного приложения

## Структура дашборда

Дашборд состоит из четырёх вкладок:

- **Главная**
- **Тип рекламной кампании**
- **Рекламный канал**
- **Тип устройств**

### 1. Главная

На главной вкладке собраны основные KPI мобильного приложения:

- выручка;
- затраты;
- ROI;
- количество заказов;
- конверсия в заказ;
- количество сессий;
- среднее время сессии.

Каждый KPI-индикатор показывает текущее значение метрики и сравнение с предыдущим периодом через **PoP — period-over-period**.

### 2. Тип рекламной кампании

Вкладка помогает оценить эффективность разных типов рекламных кампаний.

На вкладке представлены:

- ROI по типу рекламы;
- баланс доходов и расходов по типу рекламы.

Расходы отображаются как отрицательные значения, а доходы — как положительные. Такой подход помогает быстро оценить, какие типы рекламных кампаний приносят прибыль, а какие требуют оптимизации.

### 3. Рекламный канал

Вкладка показывает эффективность каналов привлечения пользователей.

На вкладке представлены:

- динамика клиентской базы по каналам привлечения;
- ROI по каналам привлечения;
- средняя длительность сессии по каналам.

Этот раздел помогает сравнить не только объём привлечённых пользователей, но и качество трафика по каждому рекламному каналу.

### 4. Тип устройств

Вкладка показывает пользовательскую активность в разрезе устройств.

На вкладке представлены:

- распределение клиентов по устройствам;
- количество клиентов MAU по устройствам;
- DAU по устройствам.

Анализ по устройствам помогает понять, с каких платформ пользователи чаще заходят в приложение и какие устройства дают наибольшую активность.

---

## Фильтры дашборда

В дашборде настроены интерактивные фильтры:

- период;
- гранулярность;
- тип рекламной кампании;
- рекламный канал;
- тип устройства.

Фильтры позволяют анализировать показатели в разных разрезах и быстро сравнивать эффективность рекламных кампаний, каналов привлечения и устройств.

## Основные выводы

- Выручка за анализируемый период составила `30 878.1` и выросла на `2.6%` к предыдущему периоду.
- Расходы на рекламу составили `15 760.8` и снизились на `50.9%`.
- ROI составил `95.9%`, что говорит о положительной окупаемости рекламных вложений.
- Количество заказов составило `5 788` и выросло на `2.3%`.
- Конверсия в заказ составила `19.9%` и выросла на `16.4%`.
- Количество сессий снизилось на `12.1%`, но при этом выручка и конверсия выросли.
- Это может говорить о том, что качество привлечённого трафика стало выше.
- По устройствам наибольшую активность показывают пользователи iPhone.
- Рекламные каналы отличаются по ROI, поэтому рекламный бюджет стоит распределять с учётом эффективности каждого канала.

## Бизнес-рекомендации

- Перераспределить рекламный бюджет в пользу каналов с более высоким ROI.
- Дополнительно изучить каналы, которые привлекают много пользователей, но показывают низкую окупаемость.
- Проанализировать причины снижения количества сессий при одновременном росте выручки и конверсии.
- Отдельно анализировать поведение пользователей по устройствам, так как активность отличается между iPhone, Android, Mac и PC.
- Оптимизировать рекламные кампании с отрицательным или нестабильным ROI.
- Использовать дашборд для регулярного мониторинга рекламных расходов, доходности и качества привлечённого трафика.
