# Дашборд «Индустрия интерактивных развлечений»

## Описание проекта

Проект посвящён анализу рынка видеоигр, пользовательского интереса и игровой активности.  
В рамках проекта был создан интерактивный BI-дашборд в Apache Superset, который помогает отслеживать ключевые показатели по играм, игрокам, достижениям, установкам и стоимости игр.

Дашборд может использоваться топ-менеджерами и аналитической командой для оценки трендов игрового рынка, анализа популярности платформ и жанров, изучения динамики цен и выявления потенциальных точек роста.

## Цель проекта

Создать аналитический дашборд, который позволяет:

- анализировать количество игр, релизов, установок и игроков;
- отслеживать динамику стоимости игр по платформам;
- изучать распределение игр по жанрам и платформам;
- оценивать активность игроков через достижения;
- сравнивать пользовательский интерес по странам, играм и платформам;
- анализировать изменение количества игроков год к году.

## Используемые данные

В проекте использовались данные за период с 2007 по 2025 год.

Данные включают информацию о:

- играх;
- игровых платформах;
- разработчиках и издателях;
- жанрах;
- поддерживаемых языках;
- ценах игр в разных валютах;
- игроках и странах;
- установках игр;
- игровых достижениях;
- истории получения достижений.

## Структура дашборда

Дашборд состоит из четырёх тематических страниц:

1. **Игровые достижения**
2. **Анализ игроков**
3. **Стоимость игр**
4. **Анализ игр**

---

## 1. Игровые достижения

Страница помогает оценить объём достижений в играх и изучить их распределение по играм, жанрам и платформам.

На странице представлены:

- общее количество достижений;
- количество достижений в каждой игре;
- количество достижений по жанру и платформе;
- средний процент редких достижений по жанрам.
  
---

## 2. Анализ игроков

Страница предназначена для анализа аудитории и пользовательского интереса к играм.

На странице представлены:

- количество уникальных игроков;
- общее количество установок за период;
- распределение игроков по странам;
- количество установок по платформам;
- распределение игроков по платформам;
- количество установок на игру по платформам;
- топ популярных жанров по установкам;
- распределение количества игроков по играм и платформам;
- изменение количества игроков год к году по платформам.

---

## 3. Стоимость игр

Страница позволяет анализировать ценовую политику игр и динамику изменения стоимости.

На странице представлены:

- средняя стоимость игры в рублях;
- средняя и медианная стоимость игр по жанрам;
- динамика изменения средней цены по платформам;
- изменение цен в процентах по играм.

---

## 4. Анализ игр

Страница помогает оценить структуру рынка игр, активность релизов и распределение игр по платформам и жанрам.

На странице представлены:

- количество игр, вышедших за период;
- количество релизов по платформам;
- распределение игр по жанрам;
- календарь игровых релизов;
- общее количество компаний-разработчиков;
- общее количество компаний-издателей.
