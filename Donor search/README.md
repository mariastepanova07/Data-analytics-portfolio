# Анализ данных DonorSearch

## Описание проекта

Проект посвящён анализу данных платформы DonorSearch — сервиса, который помогает развивать донорское движение и учитывать активность доноров.

## Цель проекта

Проанализировать активность доноров и определить факторы, которые могут влиять на количество подтверждённых донаций.

## Задачи проекта

- Определить регионы с наибольшим количеством зарегистрированных доноров.
- Изучить динамику донаций по месяцам за 2022–2023 годы.
- Найти наиболее активных доноров.
- Оценить влияние бонусной системы на активность доноров.
- Проанализировать вовлечение доноров через социальные сети.
- Сравнить активность повторных доноров.
- Оценить, как планируемые донации переходят в реальные.
- Сформулировать выводы и рекомендации для повышения активности доноров.

## Используемые инструменты

- Анализ пользовательской активности

## Основные выводы

- Наибольшее количество доноров зарегистрировано в крупных городах, особенно в Москве и Санкт-Петербурге.
- В данных есть большое количество пользователей без указанного региона, что ограничивает качество географического анализа.
- Весной, особенно в марте и апреле, наблюдаются пики донорской активности.
- Наиболее активные доноры совершают сотни подтверждённых донаций и могут быть важной аудиторией для программ лояльности.
- Доноры, получившие бонусы, в среднем совершают намного больше донаций, чем доноры без бонусов.
- Яндекс и Telegram показывают высокий уровень вовлечённости доноров.
- В данных о повторных донорах есть аномалии в датах, поэтому перед более глубоким анализом требуется очистка данных.
- Конверсия из запланированной донации в реальную остаётся низкой: 21.61% для безвозмездных донаций и 13.00% для платных.

## Бизнес-рекомендации

- Улучшить сбор данных о регионе пользователя, чтобы точнее анализировать географию донорской базы.
- Усилить маркетинговые кампании в периоды снижения активности, особенно летом и в конце года.
- Развивать программы лояльности для активных доноров: значки, сертификаты, публичное признание, бонусы.
- Расширить охват бонусной программы, так как доноры с бонусами демонстрируют более высокую активность.
- Активнее использовать Яндекс и Telegram как каналы привлечения более вовлечённых доноров.
- Проанализировать причины низкой активности пользователей из отдельных каналов, например Одноклассников.
- Создать отдельные кампании для однократных доноров, чтобы мотивировать их стать повторными.
- Улучшить коммуникацию с пользователями, которые запланировали донацию, но не совершили её.
- Перед дальнейшим анализом повторных доноров очистить данные от аномальных дат.
